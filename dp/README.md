# Dynamic Programming

This directory contains the DP study roadmap and will serve as the home for dynamic-programming practice.

## Start here

- [DP Problem Roadmap](DP_PROBLEM_ROADMAP.md) — problem references grouped by technique.

## Roadmap sections

- One-dimensional DP
- Two-dimensional DP and string DP
- Knapsack and subset DP
- Tree DP
- Bitmask DP
- Interval and optimization DP

## Practice notes

For each problem, record the state definition, transition, base cases, time complexity, and space complexity in your own words. Mark a problem complete only after you can derive and explain the approach independently.

The roadmap is a reference list; it does not indicate that every listed problem has been solved.
