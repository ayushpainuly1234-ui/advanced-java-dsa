# Backtracking

Java practice programs that explore choices recursively and undo decisions when a path cannot lead to a valid result.

## Topics covered

- Permutations: [permutation.java](permutation.java), [permutationstring.java](permutationstring.java), [arraypermutation.java](arraypermutation.java)
- Maze and path search: [mazepath.java](mazepath.java), [mazepath2nd.java](mazepath2nd.java), [fourdirectionmaze.java](fourdirectionmaze.java)
- N-Queens: [nqueen.java](nqueen.java)
- Knight moves and grid search: [knight.java](knight.java), [gridknight.java](gridknight.java)

## How to study

For each program, identify the choice, constraint, recursive call, and undo step. Dry-run at least one successful path and one failing path. These are standalone practice files; run one Java file at a time.
