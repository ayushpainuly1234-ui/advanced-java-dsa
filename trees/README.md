# Trees

Java exercises for binary trees and binary search trees (BSTs).

## Topics covered

- Traversals and level-order processing
- Tree construction
- Tree height, diameter, and other properties
- Root-to-leaf paths and path-sum problems
- Tree transformations
- BST searching and predecessor/successor operations
- Lowest common ancestor and related queries

## How to use

Open the Java file for the topic you are studying, then dry-run it on a small tree. These are standalone practice programs; run one file at a time and verify edge cases before using an implementation as an interview reference.

Backtracking and graph algorithms live in their own top-level folders rather than inside trees/.
